# What is this?

This repository contains useful links related to the BARN Tech Lab. The contents of this repo are published to: [BARN Tech Lab Links](https://bainbridgeartisanresourcenetwork.github.io/tech-lab-links/)

# How this works

We use the built-in GitHub Pages support.  Anything from the `main` branch, in the `/root` directory, is automatically published to the above-mentioned site. 
It's a simple list of links, with minimal CSS styling. Nothing complex, and that's intentional.

## To contribute
If you want to contribe other internal links, open a new branch, edit the `index.md` file with your changes, commit, and open a PR to the `main` branch. Once your PR is merged into `main` your changes will appear on the site.
